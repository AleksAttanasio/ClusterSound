# Shortcuts

On Windows `Ctrl` instead of `⌘`.

| Section | Key | Action |
|---|---|---|
| Library | `Space` | play/stop |
| | `Esc` | closes the drawer |
| | `↑` `↓` (list) | previous/next sample, with playback |
| | `Alt`+click on a class | only that class |
| Recorder | `Space` | play/pause |
| | `↑` `↓` | previous/next region |
| | `Del` | deletes the region |
| | wheel / `Shift`+wheel | zoom / scroll |
| Sequencer | `Space` | play/stop |
| | `Shift`+click / `Alt`+click / right-click on a step | accent / ghost / roll |
| | `Alt`+click on a bass note | glide |
| Compose | `Space` | play/stop |
| | `←` `→` | previous/next chord |
| | `Del` | delete |
| | `⌘D` | duplicate |
| | `V` | chord variations |
| | `⌘Z` / `⇧⌘Z` | undo / redo |
| Melody | `↑` `↓` (`⇧` = octave) | transpose |
| | `←` `→` | move |
| | `⌘A` | select all |
| | `Alt`+drag | velocity |
