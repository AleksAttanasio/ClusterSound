# Scorciatoie

Su Windows `Ctrl` al posto di `⌘`.

| Sezione | Tasto | Azione |
|---|---|---|
| Libreria | `Spazio` | play/stop |
| | `Esc` | chiude la tendina |
| | `↑` `↓` (lista) | sample precedente/successivo, con ascolto |
| | `Alt`+clic su una classe | solo quella classe |
| Recorder | `Spazio` | play/stop |
| | `↑` `↓` | regione precedente/successiva |
| | `Canc` | elimina la regione |
| | rotella / `Maiusc`+rotella | zoom / scorri |
| Sequencer | `Spazio` | play/stop |
| | `Shift`+clic / `Alt`+clic / tasto destro su uno step | accento / ghost / roll |
| | `Alt`+clic su una nota del basso | glide |
| Compose | `Spazio` | play/stop |
| | `←` `→` | accordo precedente/successivo |
| | `Canc` | elimina |
| | `⌘D` | duplica |
| | `V` | variazioni dell'accordo |
| | `⌘Z` / `⇧⌘Z` | annulla / ripeti |
| Melodia | `↑` `↓` (`⇧` = ottava) | trasponi |
| | `←` `→` | sposta |
| | `⌘A` | seleziona tutto |
| | `Alt`+trascina | velocity |
